# Task Manager Full Stack Project

## Project Overview
This is a Full Stack Task Manager application built using:

- Spring Boot
- React JS
- MySQL
- REST API
- JWT Authentication

Users can:
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Filter Tasks
- Pagination Support
- Login Authentication
